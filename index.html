원주각과 중심각 핵심 총정리

한 호에 대한 원주각과 중심각의 절대 불변 법칙
∠AOB = 2 × ∠APB
(원주각의 크기는 항상 그 호에 대한 중심각 크기의 ½배이다!)
최종 빙고 점수
1200 점

중심 O의 위치에 따른 3가지 증명 논리 비교

1 경우 1: 중심 O가 원주각의 변(AP) 위에 있을 때 기본 모델

반지름에 의해 OP = OB 이므로 △OPB는 이등변삼각형입니다. 밑각이 같으므로 삼각형의 외각 정리에 따라 ∠AOB = ∠OPB + ∠OBP = 2∠APB 가 성립합니다.

2 경우 2: 중심 O가 원주각 ∠APB의 내부에 있을 때 두 각의 덧셈

점 P에서 중심 O를 지나는 지름선 PQ를 긋습니다. 경우 1을 좌우에 각각 적용하면 ∠AOQ = 2∠APQ, ∠BOQ = 2∠BPQ 이며, 둘을 합하여 ∠AOB = 2∠APB 가 증명됩니다.

3 경우 3: 중심 O가 원주각 ∠APB의 외부에 있을 때 큰 각 - 작은 각

지름선 PQ를 긋고 큰 각에서 작은 각을 뺍니다. ∠QOB = 2∠QPB, ∠QOA = 2∠QPA 이므로 ∠AOB = 2(∠QPB - ∠QPA) = 2∠APB 로 항상 2배가 유지됩니다.

💡

증명의 핵심 열쇠 3가지!

🔴
1. 원의 반지름 = 모두 같다!

OA = OB = OP 이므로 원의 중심과 이은 삼각형은 이등변삼각형입니다.

🟡
2. 삼각형의 외각 공식

한 외각은 이웃하지 않는 두 내각의 합입니다. (외각 = a + a = 2a)

🟢
3. 전체 각의 합 또는 차

내부일 때는 합(2a + 2b), 외부일 때는 차(2a - 2b)를 이용해 ∠AOB = 2∠APB 가 성립합니다!
